# herdr-hub 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Herdr セッション内の複数コーディングエージェントを hub-spoke で調整するユーザーレベル skill `herdr-hub` を作る。

**Architecture:** repo root = skill ディレクトリ。`SKILL.md`（骨子 + references 索引）+ `references/` 7 本。通信は 3 transport（herdr / sendmessage / codex-queue）を roster が宛先ごとに選ぶ。

**Tech Stack:** Markdown（skill 文書）、YAML（roster スキーマ例）

**Spec:** `docs/superpowers/specs/2026-09-13-herdr-hub-design.md`

## Global Constraints

- 言語: 本文は日本語（コマンド・識別子・固有名詞は原語）
- skill frontmatter: `name: herdr-hub`、description は発火条件を含む
- herdr 前提チェック `test "${HERDR_ENV:-}" = 1` を全手順の前段に置く
- agent 命名規約: herdr agent name = `claude --name` = codex session name で統一（`[a-z][a-z0-9_-]{0,31}`）
- 既定値: 交代閾値 `handoff_at: 0.8`、roster 既定パス `./.herdr-hub.yml`、共有ログ `/tmp/herdr-hub/<name>.log`
- ファイル分割: SKILL.md は骨子のみ、詳細は references へ（multi-session-hub の 100 行規約に倣い、本体は索引 + 骨子に留める）
